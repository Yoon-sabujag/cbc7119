옵션 2 (단순 swap) 권장 — 시각 변화 최소 + 코드베이스 reference 일관
데스크톱 우측 패널 헤더의 호기 정보는 flex 가로 배치 + 옆에 호기 번호 18px 구조라 아이콘만 큰 사이즈로 두는 게 자연스러움. emoji 도 container 없이 28px 였음.

모바일 EvDetailModal 헤더 (L1893) 의 container 패턴 (w-9 h-9 + size=20) 은 모바일 좁은 영역에서 시각 강조 + 색 구분용으로 들어간 디자인이지만, 데스크톱은 영역 충분해 container 없이도 호기 번호/위치 텍스트와 시각 균형이 맞음.

opt 2 = 1줄 교체 (시각 변화 최소):
· emoji ⏵ Lucide 둘 다 28px size 동일
· 색상: emoji 는 native multicolor → Lucide 는 text-secondary (단색 stroke)
· 정렬: 기존 flex align-items:center + gap:12 그대로
옵션 1 (container 패턴) — 데스크톱 헤더로는 과해 보임
container 48×48 box 가 호기 번호 18px 옆에 두면 아이콘이 너무 강조 → 호기 번호와의 시각 균형 깨짐 (호기 번호가 정보 우선순위 1 인데 아이콘이 더 도드라짐).
모바일 처럼 container 36×36 + icon 20 으로 줄이면 데스크톱 28px 보다 작아져 시각 일관성도 떨어짐.
=> 옵션 1 채택 시 사이즈 추가 조율 필요 (예: w-10 h-10 + size=22 + bg-surface-active 등) — 디자인 결정 폭이 큼

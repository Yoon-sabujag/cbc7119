섹션 D — doubleCycle (DIV / 컴프) · §6.1 적용 범위 밖

DIV/컴프레셔 카드는 doubleCycle (two-lap cycle) overlay 가 있다. 중앙 trail+value arc 색만 §6.1 derive 로 바뀌고, early(info) / late(warn) overlay arc 는 그대로 유지.

60%
중앙 trail + value arc: §6.1 적용 — 60% → --accent #3b82f6
바깥 overlay arc (late 80%): m.late_color = #fb923c (warn) · 유지
안쪽 overlay arc (early 40%): m.early_color = #38bdf8 (info) · 유지
※ early/late overlay arc 는 two-lap cycle 진행 단계 구분용. §6.1 진척률 색 룰 적용 대상이 아니다.

결정 사항 + wave 계획

통일 표준 (옵션 A)
모든 자체 헤더의 타이틀:
  className="flex-1 text-title font-semibold text-text-primary" (+ 필요 시 truncate / text-center 보존)
실제 결과: 18px / 600 weight / line-height 1.4 (GlobalHeader 와 동일)
디테일 결정
1. truncate 보존 — 도면 / 소방안전 점검 카테고리 / InspectionPage CCTV 등 긴 타이틀 페이지
2. text-center 보존 — 보수교육 (back + title + spacer 대칭 구조 유지)
3. leading-tight 제거 — RemediationDetail. text-title 자체 lh 1.4 가 더 자연스러움
4. flex-1 보존 — 우측 액션 공간 확보용 (이미 다수 적용)
5. .page-title CSS — 3 페이지 (일일업무일지/점검일지출력/업무수행기록) 의 components.css 단일 수정 → font-weight 700 → 600
6. text-[16px] arbitrary 제거 — DivPage L958 (데스크) 데이터 정정
7. DivPage L429 / L897 의 text-[16px] font-bold 은 모달 안 / 본문 안이라 무수정 (헤더 외)
Wave H7 계획 (단일 atomic 가능)
합 영향: ~14 곳 (페이지별 1 곳 + InspectionPage 카테고리 8 + InspectionPage 서브 헤더 일부)
1 파일 ~3 곳 (.page-title CSS 1 + 13 페이지 className 정정) ≈ 14 라인 변경
같은 패턴 (text-body font-bold → text-title font-semibold) sed replace_all 위험 — 본문 안 동일 className 보존 위해 헤더 line range 한정 (또는 EditBlock 단일 매칭)

단일 wave H7 권장. 시각 변화: 16→18 (+2px) + weight 700→600. 모두 같은 방향 (조금 커지고 가늘어짐).
시각 변화 미리 인지
font-bold (700) → font-semibold (600) 는 weight 차이로 살짝 가늘어 보임. 다수 페이지 영향 — GlobalHeader 와 일관성 ↑ 이지만 "왜 가늘어졌지?" 사용자 느낌 가능.
대안: 옵션 A2 = 18 / 700 (GlobalHeader 도 함께 700 으로 정정). size 만 18 통일, weight 다수 컨벤션 (700) 유지. → 시각 변화 최소.

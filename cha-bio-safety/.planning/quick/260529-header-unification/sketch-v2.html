페이지 헤더 안 버튼 통일화 — v2 시안

v1 (commit 8ac3e96) 이후 사용자 추가 가이드 반영: "헤더 안에 백버튼만 있지 않음. 종류별 가로폭은 OK 다를 수 있음. 세로폭만 GlobalHeader 와 같으면 됨."
→ 가로는 종류별 자유, 세로만 32px 단일 룰 로 좁힘.

⊕ v2 단일 룰
페이지 헤더 안 모든 버튼의 세로 = 32px.
가로는 종류별 자유 (back 32 / action 텍스트 자유 padding / 엑셀 큰 padding / 배지 padding 자유).
→ 코드에서는 h-7 또는 h-[32px]. h-8 은 codebase override 로 48px 이므로 금지.
codebase 함정 — tailwind.config.js spacing override
이 리포지토리는 spacing 을 다시 정의함:
h-7/w-7 = 32px (Tailwind 기본 28 X)
h-8/w-8 = 48px (Tailwind 기본 32 X)
h-11/w-11 = 44px
→ 32px 세로를 만들 때 h-7 또는 h-[32px] 사용. h-8 쓰면 48px 됨.
→ 메모리 anchor: feedback_tailwind_w8_h8_is_48px.md

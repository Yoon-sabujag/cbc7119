§7.1 + §2.3 Pattern 4 — 저장 💾 + 버튼 색 (L596, L599, L1033 · 옵션 분기)

기존 `bg-warning` 은 tailwind config 에 없음 → 디자인 의도 확정 필요. dirty 상태 시각 cue 보존 여부도 결정.

Old (L596 / L1033 / L599)
dirty: clean:
className: {isDirty ? 'bg-warning text-text-on-accent' : 'bg-accent text-text-on-accent'}
`bg-warning` (no -bg suffix) 가 tailwind config 에 정의 안 됨 → fallback 깨질 위험

옵션 A — 단순 (bg-accent 단일)

dirty: clean:
+Save:
— `bg-warning` 폐기, 단일 bg-accent. dirty/clean 구분은 disabled 또는 opacity 로.
— 장점: 토큰 깔끔 / 단점: dirty 시각 cue 소실

옵션 B — 의미 보존 (dirty outline 톤)

dirty: clean:
no Save:
— dirty 일 때 bg-warning-bg text-warning outline (1013/1043 pill 과 일관) / clean 일 때 bg-accent text-text-on-accent CTA.
— 장점: dirty 의미 보존 + pill 톤 일관 / 단점: 토큰 2개 사용
결정 요청 옵션 A 또는 옵션 B 중 선택. Save 아이콘 사용 / 생략도 같이 결정.
응답 예: "옵션 B + Save 사용" / "옵션 A + Save 생략"
L596, L1033 className 삼항 분기 패턴은 보존 (dirty 분기 자체 유지). 색 토큰만 치환.
L599 텍스트 '💾 저장하기' → 옵션 따라 <><Save size={14} ... />저장하기</> 또는 '저장하기'

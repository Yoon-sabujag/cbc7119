### Q1. 5/12 자동 처리 모든 행

```sql
SELECT cr.id, cr.checkpoint_id, cr.session_id, cr.staff_id, cr.checked_at, cr.memo, cp.category, cp.description
FROM check_records cr
JOIN check_points cp ON cp.id = cr.checkpoint_id
WHERE cr.memo = '접근불가 개소 자동 정상처리'
  AND cr.checked_at LIKE '2026-05-12%'
ORDER BY cr.checked_at;
```

### Q2. 베이스라인 — 유도등 [접근불가] cp 목록

```sql
SELECT id, location, category, description
FROM check_points
WHERE category = '유도등' AND description LIKE '%접근불가%' AND is_active = 1
ORDER BY id;
```

### Q3. 5/12 유도등 카테고리 전체 점검 기록 (수동 점검 포함 가능)

```sql
SELECT cr.id, cr.checkpoint_id, cr.staff_id, cr.checked_at, cr.memo, cr.result
FROM check_records cr
JOIN check_points cp ON cp.id = cr.checkpoint_id
WHERE cp.category = '유도등' AND substr(cr.checked_at, 1, 10) = '2026-05-12'
ORDER BY cr.checked_at;
```

### Q4. cron telemetry (있다면)

```sql
SELECT * FROM telemetry_events
WHERE event_type LIKE 'cron%' AND substr(created_at, 1, 10) = '2026-05-12'
ORDER BY created_at;
```

## 환경 / 인증

`npx wrangler d1 execute --remote` 는 Cloudflare API 인증 필요. `CLOUDFLARE_API_TOKEN` 환경변수가 없거나 권한 부족이면 실패.

인증 실패 시: 위 SQL 들을 그대로 출력하여 사용자가 로컬에서 수동 실행할 수 있게 보고. 인증 부재는 자체 결함이 아니므로 별도 "wrangler 인증 부재" 섹션으로 표기.

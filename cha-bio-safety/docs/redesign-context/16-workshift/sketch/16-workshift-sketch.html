공휴일/주말 빨강

design-system §16-workshift 특수 지침: "공휴일 빨강은 status-danger 가 아닌 캘린더 빨강(별도 처리) — 의미 차이 주의"

→ 별도 토큰 --cal-red 신설 (다크 #ef4444 / 라이트 #b91c1c). 의미: 캘린더 표시. 점검/조치 상태의 danger 와 시각적으로 비슷해도 토큰을 분리해 향후 톤 조정 자유도 확보.

연/월 picker 결정

네이티브 <select> 유지. 이유:

  • 년도 범위 2025~2027 — chevron 으로 넘기기엔 폭 좁음
  • 월 선택은 12개 한 번에 보는 게 빠름
  • 보존 룰: useState(year/month) 로직 그대로

대안(prev/next 화살표 + 표시) 검토했으나 현 디자인 시스템 톤(정보 인지 > 미적 정제)에 더 적합한 건 select.

Today 강조 패턴

현재 구현: 2px accent border + rgba(59,130,246,0.15) bg.

시안: 2px var(--accent) border + var(--accent-soft) bg. 헤더와 duty 셀 모두 동일 강조 — 시각적 컬럼 정렬 유지.

2px border 가 inset 으로 그려져 인접 셀과 정렬 깨질 수 있음 → border-collapse: separate + border-spacing 검토 가능. 현 코드와 동일하게 border-collapse: collapse + 2px 로 진행 (육안 차이 미미).

적용 룰 — v0.1.1

이 sketch 는 다음 룰을 강제. TSX 변환 wave 에서도 그대로 인용.

  • 토큰 단일 source: surface 3 / text 3 / border 2 / accent 1 / status-safe 3 / status-info 3 / radius 3 — 이외 토큰 추가 금지
  • 카드 chrome: surface-raised + border-default 1px + radius-md + padding 12 — 모바일 / 데스크톱 동일
  • 포트 표 sub-card: surface-page + border-default + radius-sm (raised 카드 안에 page 톤 sub-card)
  • 보존기간 배지: 확정 = safe 톤 (safe-bg + safe-bar 보더 + safe 텍스트) / 추정 = info 톤 (info-bg + info-bar 보더 + info 텍스트). 두 톤 모두 좌측 6px dot.
  • 교체일자: "기존" = text-tertiary / 날짜(YYYY-MM-DD) = status-info + bold
  • 작은 컨테이너 안 12px 텍스트는 line-height 1 (배지 / 푸터 / 채널수 3 곳) — feedback_text_caption_leading_none 룰 강제
  • 그리드: 모바일 1열 gap 8 · 데스크톱 2열 gap 12 · max-width 960

금지 룰 (verify gate 강제)

  • 옛 alias 토큰 (bg / bg2 / bd / t1 / t2 / t3 / safe 단독 / warn / danger / fire / c-day 등) 0건

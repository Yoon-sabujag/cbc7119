§6.1 Progress / 호기 좌측 색바 매핑

  • 초록 (safe-bar) — 정상 호기 (1·2·5·6·8·9·11)
  • 노랑 (warning-bar) — 점검중 호기 (3·10·ES-6)
  • 주황 (fire-bar) — 고장 호기 (4호기 — 미수리)
  • 회색 (text-tertiary) + opacity 0.62 — 운행중지 (7·ES-4)

§6.2 Stat Card 좌측 3px 색바

  • 정상 11대 → safe 색바
  • 고장 1대 → danger 색바 (1대 이상 임계치)
  • 점검중 2대 → warning 색바
  • 운행중지 3대 → mute 색바

§7 Iconography (Lucide)

  • menu, refresh-cw, search, alert-triangle — 헤더
  • square — 인승용 / package — 화물용 / box — 덤웨이터 (회색 통일)
  • siren — 고장 호기 (fire 강조 예외)
  • pause — 운행중지 / x, search-x — 검색 빈상태
  • BottomNav: layout-dashboard / clipboard-list / map / wrench / menu

ElevatorPage.tsx 1:1 매핑 (1차 범위)

  • 자체 헤더 (App.tsx 헤더 숨김 패턴) — 6탭 + 검색 + 액션

  • 그룹: 투명 / 오렌지 / 기타 / 화물 / 덤웨이터 / 에스컬
  • 4 상태 (정상 / 고장 / 점검중 / 운행중지) 각 1개씩 등장
  • 검색 활성 + 검색 결과 0건 + 로딩 스켈레톤

danger (적)

warning (호박)

days ≤ 365 (D-N 안전)
info (청)

safe (녹)
1 년 이상 여유. fmtDday text 'D-N' + color var(--safe). 등록 chip(CheckCircle2 아이콘) / 신규교육 완료(daysLeft < 0) 텍스트 '완료' 도 동일 톤.

v0.1.1 룰 시각 검증 체크리스트

§6 Progress Color Rule

  • 초록 (100%) — 옥내소화전 8/8, 승강기 12/12
  • 파랑 (50~99%) — 소화기 62%, CCTV 95%, 스프링클러 88%
  • 노랑 (1~49%) — 자탐 12%, 유도등 30%, 전실댐퍼 18%
  • 회색 + opacity 0.6 (0%) — 방화셔터, 비상콘센트

§7 Stat Card 좌측 3px 색바

  • 점검 미완료 28/34 → danger 색바 (임계치 초과)
  • 미조치 7건 → fire 색바 (1건 이상)
  • 오늘 일정 3건 → info 색바 (정상)
  • 승강기 고장 1대 → danger 색바 (1대 이상)

§8 Iconography (Lucide)

  • 도면 점검 → map (회색 통일)
  • DIV 트렌드 → bar-chart-3 (회색)
  • 고장 접수 → siren (fire 강조)
  • 직원 서비스 → users (회색)
  • BottomNav: layout-dashboard / clipboard-list / map / wrench / menu

DashboardPage.tsx 1:1 매핑

  • 근무자 칩 4명 (주간/당직/비번) + 연차/공가
  • 두 배너 (오늘 점검 + 수신반 48h)
  • 통계 카드 4종 (정상 + 임계치 변형)
  • 빠른 도구 4종 / 오늘 일정 (시간 확정/미정/완료)
  • 월간 도넛 13 카테고리 (DIV/컴프 doubleCycle two-lap)
  • 데스크톱: 사이드바 + 미니 캘린더 + sticky 일정 패널
  • 모바일: BottomNav 5탭 (height + paddingBottom 패턴)
  • loading skeleton / empty 2종 (에러는 silent fallback — 현재 동작 유지)

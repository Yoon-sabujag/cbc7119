### 0.1 What this redesign DOES change

- Inline `style={{...}}` 전량 → Tailwind utility + 토큰 클래스 (`text-*`, `bg-surface-*`, `text-text-*`, `border-border-*`, `p-card`, `rounded-{sm,md,lg,pill}`)
- 옛 var() 토큰 (`--bg`, `--bg2`, `--bg3`, `--bd`, `--t1/2/3`, `--acl`, `--c-day/night/off/leave`) 0건 — 새 토큰으로 100% 치환
- 폰트 사이즈 9·10·11px → `text-caption` (12) 이상 일괄 상향
- Pill/rounded 임의 픽셀 (6/7/8/10/12/20) → `rounded-{sm,md,lg,pill}` 4단으로 정규화
- 휴가 종류 그리드 / BottomSheet / PDF 미리보기 패널의 마크업을 v0.1.1 컴포넌트 룰에 맞춤
- Lucide 아이콘 도입 (현재 코드에 없는 아이콘 → 추가). 이모지 사용 금지.

### 0.2 What this redesign DOES NOT change (NEGATIVE scope)

- **PDF 오버레이 좌표 `lp[0..16]` 17개** — `generateLeaveRequest.ts` 와 1:1. 변경 금지.
- **`calcLeaveQuota(staffId)`** — 입사일 기반 quota 계산식 변경 금지.
- **`calcProvidedMeals` / `calcWeekendAllowance` / 5500원/끼** — 식대 운영 규칙 (memory: project_meal_calc_rules). 변경 금지.
- **`HOLIDAYS_FALLBACK` 보강 로직** — 한국 공휴일 라이브러리 누락 패턴 (memory). 변경 금지.
- **`HIRE_DATES` 하드코딩 4명** — 데이터 그대로.
- **`SHIFT_OFFSETS` / `getRawShift` / `DOW_KO` / `SHIFT_COLOR`** — 근무 calc 변경 금지.
- **React Query keys / mutation 흐름 / route navigation** — 100% 보존.
- **휴가 PDF.js workerSrc, `/api/uploads`, `/templates/leave_request_preview.png`** — 변경 금지.
- **모바일 BottomSheet vs 데스크톱 3패널 분리 (`useIsDesktop()`)** — 두 폼은 같은 state(`docStartDate`, `docEndDate`, `docLeaveType`, `docReason`, `docOtherReason`) 를 공유 — 그대로 유지.

### 1.1 Tailwind 사용 룰 (cha-bio-safety 프로젝트 전체)

- `style={{...}}` **금지** (이 페이지 약 60건 → 0건이 목표)
- `lg:*` prefix는 **레이아웃 차이**(컬럼 수, 사이드바, 폼 영역 분기)에만 사용. spacing/font 분기는 token이 자동 처리 → `lg:px-6` 같은 spacing 분기 금지
- 현재 페이지의 `useIsDesktop()` 분기는 React 조건부 렌더에 한정 (3패널 vs BottomSheet) — 토큰 분기는 token 책임
- token 클래스 패턴: `bg-fire-bar` (O) / `bg-status-fire-bar` (X) — `status-` prefix 없음 (memory: feedback_tailwind_token_class_pattern)
- lucide 사이즈는 prop: `<Calendar size={18} />` — `className="w-4 h-4"` 금지 (memory)
- **w-8/h-8 함정 주의**: `tailwind.config.spacing` 에서 w-8 = 48px (기본 32 아님) — 백버튼은 `w-7 h-7` (=32) 또는 명시 픽셀 (memory: feedback_tailwind_w8_h8_is_48px)

### 3.3 Accent (10% — 액션 강조)

`--accent` (`bg-accent`, `text-text-on-accent`) — 사용 위치 **완전 열거**:

1. 달력 "오늘" 표시 칩 (현재 #3b82f6 → `bg-accent`)
2. 달력 셀 "선택됨" 상태 보더 — **결정: `border-warning-bar`** (기존 #facc15 유지). accent 는 보더가 아닌 채움 액션에만 사용.
3. 휴가 종류 버튼 "선택됨" (active) — `bg-accent text-text-on-accent border border-accent`
4. "PDF 다운로드" 데스크톱 버튼 (현재 `--acl` → `bg-accent text-text-on-accent`)
5. 식단표 업로드 영역 dragOver 시 `border-accent`
6. focus ring: `focus:border-border-focus` (= `--accent`)

**accent 사용 금지 영역:**
- 휴가 종류 11종의 카테고리 색 표현 (그건 카테고리 색)
- 요약 카드 숫자 (그건 status / 카테고리 색)
- 식단 A/B/석식 카드 보더 (그건 카테고리 색)

### 3.4 Status (의미 색 — `safe / warning / danger / info / fire`)

이 페이지는 status 시스템과 **카테고리 색 (휴가 11종 / 식단 A/B/석식)** 두 가지 색 체계를 **모두** 쓴다. 혼동 금지.

#### 3.4.1 Status 사용처 (의미 색만)

| status | 사용 위치 | 사유 |
|---|---|---|
| `safe` (`bg-safe-bg text-safe`) | 휴가 종류 버튼 **"이미 등록됨"** 상태 (`isReg` / `isRegistered`) | 등록 완료 = 성공 = safe |
| `safe` | 달력 셀 "내 연차" 색 — **카테고리 색 (#22c55e) 와 일치하므로 카테고리로 분류** | (status 가 아니라 카테고리 색이 우연 같음) |
| `warning` (`bg-warning-bg text-warning`) | "식사 미사용 N끼" 카운트 표기 (`selCell.skipped > 0`) | 식대 손실 = 주의 |

### 3.5 카테고리 색 (휴가 11종) — status / duty / accent 와 완전 별개 체계

### 7.2 leading-none 룰 (memory: feedback_text_caption_leading_none)

- 달력 셀 좌상 라벨, 우상 날짜, "오늘" 칩 → `leading-none`
- 달력 셀 우하 정보 → `leading-snug` (5px → 17px 가 1.2배 = 14.4 — 줄간격이 필요)
- 식단 카드 본문 → `leading-relaxed` (1.625 = 21px) — 메뉴 여러줄 가독성
- BottomSheet 헤더 칩 → `leading-none`
- "미N" 미사용 식수 표시 → `leading-none`

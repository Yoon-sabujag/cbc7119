chrome 3-layer 룰 (헤더 = page, NOT raised)

  • 헤더 배경: var(--surface-page) — 본 sketch 에서 변경. App GlobalHeader.tsx 의 raised 톤 기본값과 의도적으로 다름. chrome-rules §1 적용으로 헤더+본문 = page / wrapper만 = raised 3계층 정착.
  • 본문 (page-stack): var(--surface-page) — 헤더와 동일 톤. region placeholder 안쪽이 raised 카드로 채워질 때 (W2+) 비로소 layer 분리 가시.
  • BottomNav: var(--surface-raised) — 본문 위 떠 있는 chrome 으로서 한 단계 raised.

spacing 룰

  • page-padding 16px (var(--page-padding)) — 헤더와 첫 region 사이 + region 좌우.
  • section-gap 24px (var(--section-gap)) — region 사이 세로 간격.
  • BottomNav 가림 회피: page-stack padding-bottom = page-padding + 54 + 8.

  • 이 페이지 라우트(/staff-service)는 BottomNav.ITEMS 5탭(대시보드/점검/QR/조치/승강기) 어디에도 매칭되지 않는다. 따라서 활성 탭 없음 — 5탭 전부 비활성 회색(var(--text-tertiary)).

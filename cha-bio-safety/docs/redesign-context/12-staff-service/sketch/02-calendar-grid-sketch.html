cell shape · border 룰 (UI-SPEC §5.1)

  • aspect-ratio 1 (모바일) — 본 sketch 는 모바일만
  • border-radius var(--radius-sm) = 8px
  • 패딩 2px (sketch 인라인) — TSX 변환 시 p-0.5
  • 기본 border = 1px solid rgba(255, 255, 255, 0.04) — 라이트 모드도 동일 알파 (라이트는 거의 안 보임, 의도된 약한 그리드)
  • 오늘 = 2.5px solid var(--accent) + box-shadow 0 0 0 2px rgba(59, 130, 246, 0.35)
  • 선택 = 2.5px solid #facc15 (raw hex 유지 — W2 시각 확인 후 토큰화 결정)
  • blocked overlay = absolute inset 0 + bg rgba(0, 0, 0, 0.25)

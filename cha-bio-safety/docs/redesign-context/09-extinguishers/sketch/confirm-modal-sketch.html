09. 소화기 확인 모달 4종 — v0.1.1 재디자인 시안 (wave 5)

ConfirmModal (l.1075-1103) 의 4 호출처 (분리 / 폐기 / 삭제 / 스왑) + loading 변형 sketch. primaryStyle = 'acl' (일반 액션) | 'danger' (위험 액션) 2 톤 분기. maxWidth 320 (다른 모달 360 보다 작음).

V1 · 분리 (primary acl, "분리")

V2 · 폐기 (primary danger, "폐기")

confirmDispose — 폐기 처리, 더 이상 배치 불가. 점검 이력 보존.

소화기 폐기
이 자산은 폐기 처리되어 더 이상 배치할 수 없습니다. 점검 이력은 보존됩니다.

V3 · 삭제 (primary danger, "삭제" — 영구 삭제, 되돌릴 수 없음)

confirmDelete — hard delete, 점검 기록 없는 경우만. 강한 위험 표현.

소화기 삭제
이 자산은 점검 기록이 없어 영구 삭제됩니다. 되돌릴 수 없습니다.

V4 · 스왑 (primary acl, "스왑")

swapTarget — 양쪽 자산이 위치를 서로 바꿈. 양쪽 배치 동시 변경.

위치 스왑
「사무동 3F · 계단실」 위치 소화기와 서로 바꿉니다. 양쪽 배치가 동시에 변경됩니다.

V5 · 처리 중 (loading=true, "처리 중…")

소화기 폐기
이 자산은 폐기 처리되어 더 이상 배치할 수 없습니다. 점검 이력은 보존됩니다.

위험도 분기 — primaryStyle 의 의미

  • acl 톤: 양방향 가역 액션 (분리 → 재배치 가능 / 스왑 → 다시 스왑 가능)
  • danger 톤: 불가역 액션 또는 데이터 상태 변경 (폐기 = 비가역 / 삭제 = 영구 삭제)

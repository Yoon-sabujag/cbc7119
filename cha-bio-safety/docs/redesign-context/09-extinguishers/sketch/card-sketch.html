적용 룰 — v0.1.1 (카드 영역)

8 viewport 가 커버하는 카드 변형 매트릭스. TSX 변환 wave 에서 verbatim 인용.

  • 카드 wrapper: surface-raised + border-default 1px + radius-md + padding 12. expanded = accent 1.5px border. disposed = surface-sunken + opacity 0.6.
  • 상태 badge 3종 — 배치됨 = accent-bg + accent text / 미배치 = status-danger-bg + status-danger text / 폐기 = status-warning-bg + status-warning text. 좌측 6px dot.
  • type 이름: fontSize 14 / fontWeight 700 / text-primary
  • 제조·증지번호: fontSize 12 / fontWeight 500 / text-secondary / mono
  • location: fontSize 12 / fontWeight 500 / text-tertiary / 좌측 dot (이모지 핀 마커 대체)
  • 교체 warning chip 2색 — warn+imminent = status-warning 페어 / danger = status-danger 페어. 좌측 dot + 텍스트 "교체 도래/임박/초과". (원본 코드 그대로 — chrome 의 chip 은 3색이지만 카드는 2색)
  • DetailField grid 2열 / gap 3px 12px / fontSize 12 / border-top default / label fontWeight 400 text-tertiary / value fontWeight 700 text-primary (mono 옵션)
  • Action button: flex 1 / height 36 / radius-sm / fontSize 12 / fontWeight 700. 기본 = surface-sunken + text-primary + border-strong. danger = status-danger-bg + status-danger + status-danger-bar.
  • 3 state 별 action 분기 — unmapped-clean: 정보수정/배치/삭제(d) / unmapped-inspected: 정보수정/배치/폐기(d) / mapped: 정보수정/분리(d)

결정 사항 (사용자 컨펌 필요)

Q1. 라벨 폰트 크기 — 현재 10.5px. 노안 룰 (12px 마지노) 적용 어떻게?
옵션: (a) 10.5px 유지 / (b) 11px 격상 / (c) 12px (text-caption) 격상
시안 권장: 11px — 범례 row 가 모바일에서 2줄 wrap 안 되도록. 12px 격상 시 wrap 빈도 증가.
Q2. 점검 상태 색 — 현재 인라인 hex (#22c55e/#eab308/#ef4444/#3b82f6).
옵션: (a) hex 유지 / (b) status-bar 토큰 (bg-safe-bar / bg-warning-bar / bg-danger-bar / bg-info-bar)
시안 권장: (b) status-bar 토큰 — 다크/라이트 분기 자동, 일관성. 다크 색 값은 hex 와 거의 동일.
Q3. 미배치 마커 빨강 배지 — 현재 인라인 #ef4444.
시안 권장: bg-danger-bar (Q2 와 일관)
Q4. 점검 상태 4종에 "fault" 포함 — 현재 코드는 ['normal', 'caution', 'fault', 'resolved']. fault 는 STATUS_COLOR 에서 bad 와 동일 색 (#ef4444).
메모리 feedback_inspection_unresolved_color: 미조치 = fire (주황). fault 는 점검 결과 자체가 불량.
시안 권장: fault 라벨 "불량" 유지 + 색은 bg-danger-bar (빨강) — 점검 결과로서의 불량. 마커 popup 의 미조치 fire 와는 분리.

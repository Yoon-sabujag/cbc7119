적용된 룰 (inspection-modal-chrome-rules.md §7.2)

  • 헤더 bg-surface-page border-b border-border-default flex-shrink-0 (이전: raised → page 로 fix)
  • 도면 종류 탭 / 층 칩 wrapper bg-surface-raised border-b border-border-default px-3.5 py-2 flex-shrink-0 + 라벨 (“도면 종류” / “층 선택”) 신규 추가
  • 라벨 text-caption font-semibold text-text-tertiary mb-1.5 tracking-wider
  • 도면 종류 탭 = flex-1 basis-0 min-w-0 inline-flex items-center justify-center gap-1.5 px-2 py-2 rounded-sm text-label font-bold whitespace-nowrap 균등 분배
  • 층 칩 = flex-shrink-0 px-3.5 py-1.5 rounded-sm text-label font-bold whitespace-nowrap 가로 스크롤
  • 선택 = border-[1.5px] border-accent bg-accent text-text-on-accent
  • 비선택 = border border-border-strong bg-surface-page text-text-secondary (3-layer 안 박스 윤곽)
  • 데스크톱 헤더 h-[54px] px-5 + 뒤로가기 버튼 없음 (사이드바 nav)
  • 모바일 헤더 px-4 py-2.5 + 뒤로가기 버튼 w-8 h-8 rounded-sm bg-surface-sunken border border-border-default
  • 우측 액션 (마커 편집 / 축소 보기) h-input px-3 rounded-sm bg-surface-sunken border border-border-default text-text-secondary text-caption font-semibold

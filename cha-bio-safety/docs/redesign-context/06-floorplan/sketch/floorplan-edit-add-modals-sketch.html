적용된 룰 (Wave 1/2 패턴 mirror + 02 inspection-modal-chrome-rules)

  • 모달 wrapper: w-[90%] (또는 85%) max-w-[340|320px] max-h-[80%] overflow-y-auto bg-surface-raised border border-border-default rounded-md p-5
  • 백드롭: absolute inset-0 z-[40] bg-black/60 flex items-center justify-center p-4 (도면 캔버스 안 — fixed 아님)
  • 타이틀: text-body font-bold text-text-primary mb-4 (16px)
  • 라벨: text-caption text-text-tertiary mb-1.5 (구역 / 유도등 종류 / 개소명 / 라벨)
  • zone 3택 (02 §3.2 mirror + ZONE_ICONS): flex-1 basis-0 min-w-0 inline-flex items-center justify-center gap-1.5 px-2 py-2 rounded-sm text-label font-bold + 아이콘 size={14} (연구동 FlaskConical / 사무동 Building2 / 지하 TrainFront)
  • marker 종류 grid (옵션 카드): grid grid-cols-3 gap-1.5 + flex flex-col items-center gap-0.5 px-1 py-2 rounded-sm + <MarkerIcon size=16> (sketch 의 lucide 는 placeholder — 실제 TSX 는 기존 MarkerIcon 그대로) + 2-line text-caption font-semibold leading-none
  • 선택 상태: border-[1.5px] border-accent bg-accent text-text-on-accent / 비선택: border border-border-default bg-surface-page text-text-secondary
  • input: w-full px-3 h-input rounded-sm bg-surface-page border border-border-default text-text-primary text-label outline-none box-border + placeholder:text-text-tertiary
  • 소화기 분리 (mappedExt 있음): flex-1 h-input rounded-sm bg-danger-bg border border-danger-bar/40 text-danger text-label font-semibold (위험 outline 톤)
  • 소화기 배치 (mappedExt 없음): w-full h-input rounded-sm bg-accent text-text-on-accent text-label font-bold (일반 진행)
  • 액션 row 취소: flex-1 h-input rounded-sm bg-surface-sunken border border-border-default text-text-secondary text-label font-semibold
  • 액션 row 저장/추가: flex-1 h-input rounded-sm bg-accent text-text-on-accent text-label font-bold
  • 옛 var() 토큰 (--bg2/--bg3/--bd/--bd2/--t1/--t2/--t3/--acl/--danger) 0건
  • 옛 rgba 인라인 (rgba(239,68,68,...)) 0건 — danger 토큰 페어로 교체

시안 한정 (TSX 변환 시 교체)

  • marker 종류 grid 안의 lucide 아이콘 (square/triangle/diamond/flame/droplet 등) 은 sketch placeholder — 실제 TSX 는 기존 <MarkerIcon markerType={mt.key} color={...} size={16}/> 호출 그대로 사용
  • zone 아이콘 (FlaskConical/Building2/TrainFront) 은 TSX 도 동일하게 lucide-react 사용

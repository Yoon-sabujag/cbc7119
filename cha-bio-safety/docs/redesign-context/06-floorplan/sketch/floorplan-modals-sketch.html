06 FloorPlanPage Wave 1 모달 통일 룰

  • v0.1.1 토큰만 — 옛 alias (--bg/--bg2/--bg3/--bd/--bd2/--t1~3/--acl/--warn/--danger) 0건.
  • 이모지 X 문자 폐기 — lucide x / lucide check-circle / lucide alert-triangle / lucide x-circle / lucide camera 사용.
  • 그라디언트 0건 — CTA 는 단색 bg-accent text-text-on-accent. 05 RemediationDetailPage mirror.
  • 모달 wrapper 일관성: bg-surface-raised border border-border-default rounded-md p-5 (모바일 max-width 320 · 데스크톱 max-width 400).
  • 점검 결과 3택 (B 모달): 02 InspectionPage 패턴 mirror — 선택 시 border-[1.5px] + status 토큰 페어 (safe-bg/safe / warning-bg/warning / danger-bg/danger), 비선택 border border-border-default bg-surface-page text-text-secondary.
  • 조치 피커 3택 (C 모달): 증상 피커와 동일 — 선택 1.5px accent / 비선택 1px border-default + page. 라벨 없이 바로 row.
  • input / textarea bg: 룰 §6.2 는 본문이 surface-page 일 때 raised 패턴. 모달 안에서는 wrapper(raised) → input(page) 분기로 시각 구분 (모달 내부 컨테이너 패턴).
  • 정보수정 / 소화기분리 (h-8 row): text-caption + leading-none 명시 (메모리 룰 feedback_text_caption_leading_none).
  • 마커 정보 popup: 아이콘 박스 = status 토큰 페어 (bg-{status}-bg border-[1.5px] border-{status}) + statusLabel 색 일치. uninspected 만 surface-sunken + border-default 회색 톤.
  • 메모리 룰 feedback_inspection_unresolved_color: 미조치 = fire (주황) 톤 / 완료 = safe (녹). danger 가 아닌 fire 사용.
  • 지적 메모 배지 (C 모달): bg-warning-bg border border-warning-bar rounded-sm px-2.5 py-1.5 text-caption text-warning — 검은 본문 위에서 노란 카드로 부각.
  • PhotoButton placeholder: bg-surface-page border border-dashed border-border-default + lucide camera + "촬영" 라벨 (text-caption leading-none).
  • 액션 row 단색 accent: 취소 bg-surface-sunken border border-border-default + 저장/조치 완료 bg-accent text-text-on-accent. 높이 h-input.

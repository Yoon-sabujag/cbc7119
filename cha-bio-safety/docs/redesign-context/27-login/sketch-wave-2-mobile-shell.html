  • 모바일 헤더 padding (line 204) = 16px 20px 24px + 데스크톱 카드 헤더 padding (line 180) = 24px 24px 20px 서로 다름. 두 헤더 패턴 source verbatim 보존.
  • placeholder "{inner}" 영역 4 frame 모두 동일 — W3 직원 카드 그리드 + W4 로그인 폼 + footer 안내문 mounting point.

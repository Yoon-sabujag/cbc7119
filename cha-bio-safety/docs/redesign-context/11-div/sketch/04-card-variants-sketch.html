옵션 B (영역 3 채택) 패턴 기반 — 정상/주의/이상 3 변형

• 카드 border: 정상 = border-default 1px (모든 변) / 주의 = border 1px + 좌측 4px status-warning-bar / 이상 = border 1px + 좌측 4px status-danger-bar (§6.2 negative rule — 정상은 흑백, 주의/이상만 좌측 색바)

• 카드 헤더 우측 배지: 주의 = "주의" 12px font-bold text-warning-bar / 이상 = "이상" 12px font-bold text-danger (정상은 배지 없음)

• 컬럼 값 색은 각 컬럼 individual status 기준 (DivPage.tsx pressureStatus()):

- ok → 원래 컬럼 색 (1차 accent / 2차 fire-bar / 세팅 safe-bar)

- warn (±10%) → text-status-warning (#fbbf24)

- danger (±20%) → text-status-danger (#f87171)

샘플 시나리오

- #1 정상 — 모든 컬럼 ok

- #2 주의 — 1차만 warn (직전 대비 ±10%), 2차/세팅은 정상 색 유지, 카드 border + "주의" 배지

- #3 이상 — 2차 danger (직전 대비 ±20%), 1차/세팅은 정상 색 유지, 카드 border + "이상" 배지

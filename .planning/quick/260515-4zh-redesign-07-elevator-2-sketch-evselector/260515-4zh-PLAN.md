# 260515-4zh — redesign/07-elevator 2차 sketch (EvSelector + EsNodeMap + EsBtn)

## Background

1차 sketch (`260510-c2z`, `elevator-sketch.html`) 는 list 탭 4-type 그룹 + 단순 카드 리스트만 시안화. 이때 의도적으로 미뤘던 영역:

- **EvSelector 5그룹 분류** (투명/오렌지/기타/화물/덤웨이터) — 모달 안 호기 선택 UI 전용
- **EsNodeMap 에스컬 노선도** (4 노선 FAULT / 6 노선 ANNUAL) — 동일 모달 전용

이 영역은 `FaultNewModal`, `InspectModal`, `RepairNewModal` 3 개 모달에서 공통으로 쓰이는 호기 선택 헬퍼 (`EvSelector`) 안에 들어간다. 모달 컨테이너 본문(필드/제출 등) 과는 독립된 디자인 의사결정이라 별도 2차 sketch 로 분리.

Wave 1 TSX 변환 (`260515-3mc`) 에서 `ElevatorIcon` 커스텀 SVG 가 신설됐고 토큰 매핑(`bg-accent` / `text-text-on-accent` / `bg-surface-sunken` / `bg-fire-bg` / `text-fire` / `bg-danger-bg` / `text-danger` / `bg-safe-bg` / `text-safe` / `border-default`) 권위가 확정됐기 때문에, 본 시안은 이 토큰만 사용해서 디자인.

## 시안 범위

### 4 viewport × EvSelector 2 mode × FAULT/ANNUAL 2 variant

| Viewport | Mode | Variant | 주요 시각 결정 노출 |
|---|---|---|---|
| 모바일 다크 | 엘리베이터 | FAULT | 4그룹 (덤웨이터 X), 호기 비선택/선택/고장 3상태, 동적 컬럼 (3/3/2/2) |
| 모바일 라이트 | 에스컬 | FAULT | 4 노선 (B1↔M 제외), EsBtn 비선택/하행선택/상행선택 3상태, 가운데 세로 라인 |
| 데스크톱 다크 | 엘리베이터 | ANNUAL | 5그룹 (덤웨이터 포함, 1대 단독 grid), 호기 3상태 + empty state |
| 데스크톱 라이트 | 에스컬 | ANNUAL | 6 노선 (B1↔M 포함), M층 layout, EsBtn 3상태 |

(모바일 두 viewport 가 종류 토글 양쪽 active 상태를 각각 보여줘서, 토글 전환 결과를 동시에 비교 가능. 데스크톱도 동일 패턴.)

### 디자인 의사결정 영역 (반드시 시각화)

#### 1. 종류 선택 토글 (현 코드 line 1948-1957)

- 2 옵션 좌우 동일 폭 (`flex:1 flex:1`)
- 활성: `bg-accent` + `text-text-on-accent` (Wave 1 TSX 토큰)
- 비활성: `bg-surface-sunken` + `text-text-tertiary`
- 아이콘 (이모지 → lucide/custom):
  - 엘리베이터: `ElevatorIcon` (커스텀 SVG, Wave 1 신설)
  - 에스컬레이터: `MoveDiagonal` (lucide)
- 터치 타겟: 모바일 44px / 데스크톱 40px

#### 2. 엘리베이터 호기 그리드 (현 코드 line 1963-1990)

- 그룹 라벨: `uppercase` + `tracking-wider`, `text-text-tertiary`, 12px
  - 그룹 라벨 텍스트로만 그룹 구분 (§6.3 회색 통일 룰 — 별도 그룹 아이콘 X 결정. 라벨 텍스트로 충분)
- 호기 버튼 그리드: `grid-cols-[repeat(N,1fr)]` 패턴 (N = 그룹 호기 수: 3/3/2/2/1)
- 호기 버튼 상태:
  - 비선택: `bg-surface-sunken` + `text-text-primary`, border-default
  - 선택: `bg-accent` + `text-text-on-accent` + `outline-2 outline-accent`
  - 고장: `bg-fire-bg` + `text-fire` + `Siren` (또는 `AlertTriangle`) lucide 아이콘 우측
- 라벨 텍스트: `{N}호기` (이모지 `⚠️` 제거 → lucide 아이콘으로 대체)
- 터치 타겟: 모바일 44px / 데스크톱 40px

#### 3. 에스컬 노선도 (EsNodeMap, 현 코드 line 1911-1934)

- 컨테이너: `bg-surface-raised` + `rounded-lg` + `p-3` + `relative`
- 가운데 세로 라인: `absolute left-1/2 top-5 bottom-5 w-px bg-border-default` (현 `var(--bd2)` → `border-default` 토큰)
- 행 구조: 1행 = 1 transition (좌=하행, 우=상행)
- 층 레이블 행: `text-center font-bold text-text-secondary text-sm` (3층 / 2층 / B1층 / [M층 ANNUAL 한정])
- 버튼 행: `flex gap-2`, 좌우 EsBtn 동일 폭

#### 4. EsBtn (현 코드 line 1893-1908)

- 컨테이너: `flex-1 p-2.5 rounded-md flex flex-col items-center gap-1`
- 상태:
  - 비선택: `bg-surface-raised` + `text-text-primary`
  - 선택-하행: `bg-danger-bg` + `outline-2 outline-danger` + `text-danger` + `ChevronDown` lucide
  - 선택-상행: `bg-safe-bg` + `outline-2 outline-safe` + `text-safe` + `ChevronUp` lucide
- 라벨: `{N}호기` 14px 700, dir 텍스트 (`하행` / `상행`) 13px 600 (10px 금지 — 노안 친화)
- **§6.1 색 의미 코멘트** 명시: `danger=하행 방향 표시 (고장 의미 아님)`, `fire=호기 고장 미수리 (별도)` 차이

#### 5. 빈 상태 / Empty state

- `elevators` 배열 비어있을 때 — 현 코드는 별도 처리 없음 (그룹 map 결과 비면 그냥 빈 div)
- 시안에서 신규 디자인: `bg-surface-sunken` + `text-text-tertiary` + lucide icon (예: `Inbox` 또는 `AlertCircle`) + "등록된 호기가 없습니다" 메시지
- 데스크톱 다크 viewport 에 1회 노출 (덤웨이터 그룹 또는 별도 데모 슬롯)

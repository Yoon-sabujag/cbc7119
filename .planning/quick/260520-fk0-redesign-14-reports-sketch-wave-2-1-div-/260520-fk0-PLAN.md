## 8. 라이트 frame mirror

다크 frame 의 HTML markup 을 1:1 복사. 차이점:
- `<section class="frame frame-light" data-theme="light">` — wrapper 에 data-theme="light" 부여
- frame-label 텍스트 = "라이트 모드 (393px 모바일)"
- (CSS 는 동일, 토큰만 라이트 모드 값 자동 적용)

CSS attribute selector 패턴:
```css
[data-theme="light"] {
  --surface-page: #ffffff;
  /* ... 위 fence 안 라이트 토큰 */
}
```

CSS 가 `:root, [data-theme="dark"]` (다크) + `[data-theme="light"]` (라이트) 둘 다 정의되어 있고, frame wrapper 에 `data-theme` 속성을 부여하면 child element 에서 `var(--surface-page)` 가 자동 라이트 값 적용. 13-schedule sketch-wave-1.html 패턴 그대로.

- `padding: '10px 4px'` — `px-1 py-2.5` 가능. **결정: arbitrary `px-1 py-[10px]`** (Tailwind py-2.5=10px 일치, 변환 채택)
- `fontSize: 7/8/9/14px` — Tailwind 미지원 → arbitrary `text-[7px]` `text-[8px]` `text-[9px]` `text-[14px]`
- `gridTemplateColumns: 'repeat(3, 1fr)'` → `grid-cols-3`
- `gridTemplateColumns: '60px 1fr 1fr 1fr'` → arbitrary `grid-cols-[60px_1fr_1fr_1fr]`
- `gridTemplateColumns: '80px repeat(3, 1fr)'` → arbitrary `grid-cols-[80px_repeat(3,1fr)]`
- `letterSpacing: '0.04em'` → arbitrary `tracking-[0.04em]`
- `borderRadius: '16px 16px 0 0'` (바텀시트) → arbitrary `rounded-t-2xl` (16px = rounded-2xl)
- `fontFamily: 'JetBrains Mono, monospace'` → arbitrary `font-[JetBrains_Mono,monospace]`
- `transform: rotate(-90, ${vx}, ${vy})` — SVG 동적 값, inline 유지
- SVG attribute (fontSize="11" 등) — SVG 표준 attribute, className 비변환
- IntervalBar 의 `color` prop string — 인라인 SVG fill/stroke, prop 유지

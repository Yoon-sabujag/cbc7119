## Step 2 — `<style>` 블록 (인-page CSS)

### 2-1. tokens.css verbatim embed

`:root, [data-theme="dark"] { ... }` 블록과 `[data-theme="light"] { ... }` 블록을 **tokens.css 에서 verbatim 복사**. Spacing / Radius / @media (min-width: 768px) 블록도 모두 포함. **Alias 블록 (--bg, --bg2, --bd, --t1, --acl 등) 은 sketch markup 에서 절대 사용하지 않으므로 verbatim embed 만 하고 markup 에선 0회 참조.**

기본 `[data-theme="dark"]` 이 base — body 가 그대로 다크. 라이트 모드는 `.light-frame` 컨테이너로 scoped (W8 패턴). 즉:

```css
.light-frame {
  /* 라이트 토큰 verbatim 재정의 — tokens.css [data-theme="light"] 블록을 .light-frame 셀렉터로 재선언 */
  --surface-page: #ffffff;
  --surface-raised: #f6f8fa;
  ... (전체 라이트 토큰)
}
```

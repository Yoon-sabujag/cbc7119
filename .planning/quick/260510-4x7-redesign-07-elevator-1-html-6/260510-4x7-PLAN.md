# 260510-4x7 — redesign/07-elevator 1차 시안 HTML

## 목적

ElevatorPage.tsx (3209라인, 6탭 + 5모달 + 호기상세) 를 design-system v0.1.1 기준으로 재디자인하기 위한 1차 시안 HTML.

3209라인 + 다양한 컴포넌트라 단계별 진행. **이번 1차는 페이지 골격(컨테이너 + 헤더 + 호기 그리드 + 노선도) 까지만**, 모달/KOELSA 는 2·3차로 분리.

## 1차 시안 범위

### 포함 (반드시 시안에 들어가야 함)

1. **페이지 컨테이너 + 자체 헤더**
   - App.tsx 헤더 숨김 (`DESKTOP_HEADER_HIDE_PATHS` 패턴) — 자체 풀헤더가 책임
   - 6개 탭: list(목록) / fault(고장) / repair(수리) / inspect(점검) / annual(연간) / safety(안전관리자)
   - 검색 입력 (호기 번호/위치 검색)
   - 우상단 액션 (admin: 새로고침, 사용자: 보기)
   - 모바일은 BottomNav 와 자체 헤더 동시 노출 (자체 헤더는 스크롤 시 sticky)
   - 데스크톱은 사이드바 + 자체 헤더만

2. **호기 그리드 (list 탭 기본 뷰)**
   - 11호기 엘리베이터 + 6대 에스컬레이터
   - 그룹별 카드 묶음 (시안에서 그룹 라벨 명시):
     - 투명 (1·2호기)
     - 오렌지 (3·4호기)
     - 기타 (5·6·7·8호기)
     - 화물 (9·10호기)
     - 덤웨이터 (11호기)
     - 에스컬레이터 (E1~E6)
   - 카드 내용: 호기 번호 / 위치 / 상태 배지(정상/고장/점검중/운행중지) / 마지막 점검일
   - **카드 좌측 3px 색바** = 상태 (Progress Color Rule 응용 — fault=fire, 점검중=warning, 정상=safe, 정지=danger)
   - 카드 hover 효과 (border-color 강화 + translateY(-1px))
   - 0% 또는 비활성 카드 opacity 0.6

3. **에스컬레이터 노선도 섹션**
   - 좌/우 호기 + 층 라벨 행 (현재 ES_NODES_FAULT 데이터 구조 모방)
   - 각 노드 = 작은 dot + 호기 번호. 색은 상태별 분기.

4. **상태 변종 (시안 내 모두 보여주기)**
   - 정상 호기 카드 / 고장 호기 카드 / 점검 중 호기 카드 / 운행 중지 호기 카드 — 각 1개씩
   - 검색 필터 활성화 시 (입력값 있고 결과 N건) 모습
   - 빈 상태 (검색 결과 0건)
   - 로딩 상태 (스켈레톤)

### 제외 (1차 시안 X)

- 5개 모달 (고장 신고 / 수리 등록 / 점검 기록 / 호기 상세 / 조치) — **2차 시안**
- KOELSA 이력 카드 (KoelsaHistorySection) — **3차 시안**
- 검사성적서 PDF 표시 — 3차에서 KOELSA 와 같이
- 6개 탭 중 list 외의 탭 본문 (fault/repair/inspect/annual/safety) — 1차 시안에는 탭 헤더만, 본문은 2~3차

1차 시안 끝부분에는 모달/KOELSA 자리에 **placeholder 박스** ("2차 시안 — 5 modals 예정", "3차 시안 — KOELSA 이력 예정") 만 표시.

## 시안 포맷 (01-dashboard 와 일치)

- 단일 HTML 파일 (`elevator-sketch.html`)
- Tailwind CDN
- Pretendard Variable CDN
- Lucide CDN (커스텀 아이콘은 inline `<svg>` 로 구현)
- `[data-theme="dark"]` / `[data-theme="light"]` 컨테이너로 4 viewport 분리
- 4개 viewport 가 한 페이지에 세로 배치 (모바일 다크 → 모바일 라이트 → 데스크톱 다크 → 데스크톱 라이트)
- 각 viewport 시작에 헤더 라벨 ("📱 모바일 다크" 등)
- 토큰은 `[data-theme]` 안에 인라인 정의 (01-dashboard 패턴)
- alias 변수 (`--bg`, `--t1` 등) 도 같이 정의해서 시각적 디버깅 편의

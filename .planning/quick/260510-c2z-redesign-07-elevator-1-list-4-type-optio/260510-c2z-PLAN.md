# 260510-c2z — redesign/07-elevator 1차 시안 재작성

## Background

`260510-4x7` 1차 시안 (`elevator-sketch.html`, 2013줄) 작성 시 ElevatorPage.tsx 의 두 가지 별개 데이터 구조를 혼동:
- **List 탭 그룹**: `e.type` 4분류 (passenger/cargo/dumbwaiter/escalator) — 단순 카드 리스트
- **EvSelector 그룹**: `EV_GROUPS_FAULT/ANNUAL` 5그룹 (투명/오렌지/기타/화물/덤웨이터) — 고장/수리/점검 모달 안 호기 선택 UI 전용

기존 시안은 EvSelector 의 5그룹 분류와 EsNodeMap 노선도를 list 탭에 잘못 배치. 사용자가 "원래 페이지 list 는 다른 엘베들처럼 그냥 카드로만 표시. 노선도는 수리/고장 모달에서만." 라고 정정.

추가로 §7.1 (이모지 금지) 적용 — 코드 원본 emoji (`🛗/📦/🔲/↕️`) → Lucide 매핑.

## 정정 사항

### List 탭 구조 (실제 코드 line 1039-1098 기준)

```
인승용 (passenger) — 8대
  └ EV-01 ~ EV-08, 카드 형태
화물용 (cargo) — 2대
  └ EV-09 ~ EV-10, 카드 형태
덤웨이터 (dumbwaiter) — 1대
  └ EV-11, 카드 형태
에스컬레이터 (escalator) — 6대
  └ ES-01 ~ ES-06, 카드 형태 (이전 시안의 노선도/배치도 X)
```

### Option A 아이콘 매핑 (사용자 결정)

| Type | Lucide |
|---|---|
| passenger (인승용) | `ArrowUpDown` |
| cargo (화물용) | `Package` |
| dumbwaiter (덤웨이터) | `UtensilsCrossed` (B1 식당↔2F 음식 운반 메타포) |
| escalator (에스컬레이터) | `ChevronsUpDown` |

§6.3 정신: 아이콘 색은 모두 회색(`text-secondary`) 통일. 종류 구분은 그룹 라벨로.

### 호기 카드 내용 (실제 코드 기준)

각 카드:
- **type 아이콘** (위 매핑) — 좌측 슬롯 40px (회색)
- **호기 번호** + 위치 — `{ev.number}호기` + 회색 작은 글씨로 위치
- **에스컬레이터의 경우**: `(공단 N호기)` 추가 표시
- **하단 메타**: 최근 점검일 또는 "점검 기록 없음" + 미해결 N건 (active_faults > 0 일 때 danger 색)
- **우측 상태 배지**: 정상/고장/점검중/운행중지 (§6.1 색 매핑)
- **다음 점검 배지** (있을 때): `D-N` (warning) / `검사 초과` (danger) / `기록 없음` (info)
- **우측 끝**: chevron-right 화살표 (Lucide `ChevronRight`)
- **카드 좌측 3px 색바**: 상태 색 (§6.1) — 정상=safe-bar, 점검중=warning-bar, 운행중지=danger-bar, 고장=fire-bar

# SUMMARY — 데스크톱 대시보드 달력·점검현황 카드 바닥 정렬

## 근본 원인
달력 카드의 `min-h-[220px]` 때문에, 우측 컬럼(라이브 272 + 달력 + 오늘일정 126 + gap 32 ≈ 658)이
일반 뷰포트의 Row3 가용높이(≈490~650)보다 커질 때 달력이 220 밑으로 못 줄고 아래로 삐져나와
달력 바닥이 점검현황 바닥보다 내려갔다(실측 델타 −17/−157/−197). 빠른도구·오늘일정(둘 다 126px)은
문제 아님.

## 해법 경위: Option B → (스크롤 발생) → Option A 최종
1차 Option B(Row3 `min-h-0` 제거 → 달력 풀사이즈 + 부족 시 페이지 스크롤) 배포(c3613877).
그러나 사용자 뷰포트(vh<978)에서 **대시보드에 세로 스크롤이 생겨** 사용자가 원치 않음.

→ **Option A 로 전환(최종, 배포 c...대기)**: Row3 `min-h-0` 복원(대시보드 항상 한 화면) +
달력 카드 `min-h-[220px]` → `min-h-0`. 원본 대비 실질 변경 = 달력 min-height 완화 1건.

```
Row3:  flex gap-4 flex-1 min-h-0            (B 되돌림 = 원복)
달력:  ... flex-1 min-h-[220px] ...  →  ... flex-1 min-h-0 ...
```

효과: 남는 높이를 달력이 흡수 → 우측 컬럼이 Row3 안에 들어가 **페이지 스크롤 없음** +
두 카드 바닥 정렬 유지. 공간 넉넉하면 달력 풀사이즈, 부족하면 달력만 내부(overflow-y-auto)에서 축소.

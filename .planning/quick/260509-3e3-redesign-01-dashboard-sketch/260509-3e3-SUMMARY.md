## v0.1.1 룰 시각 확인 결과

### §6 Progress Color Rule
시안에 4가지 구간 모두 분포:
- **safe (100%)**: 옥내소화전 8/8, 승강기 12/12 — 초록
- **info (50~99%)**: 소화기 62%, 피난계단 75%, 스프링클러 88%, CCTV 95%, DIV/컴프 합산 42% (단 inner ring 60% 영역 파랑) — 파랑
- **warning (1~49%)**: 자탐 12%, 유도등 30%, 전실댐퍼 18% — 노랑
- **0% (회색 + opacity 0.6)**: 방화셔터, 비상콘센트 — design-system §6.3 정확 반영

### §7 Stat Card
- 점검 미완료 28/34 → 좌측 3px `--status-danger-bar` (임계치 초과)
- 미조치 7건 → 좌측 3px `--status-fire-bar` (1건 이상)
- 오늘 일정 3건 → 좌측 3px `--status-info-bar` (정상 임계치)
- 승강기 고장 1대 → 좌측 3px `--status-danger-bar` (1대 이상) + "검사도래 2" 워닝 배지

### §8 Iconography
모든 lucide 아이콘은 `--text-secondary` 회색 통일.
- 도면 점검: `map`
- DIV 트렌드: `bar-chart-3`
- 고장 접수: `siren` (fire 색만 예외)
- 직원 서비스: `users`
- BottomNav 5탭: `layout-dashboard / clipboard-list / map / wrench(+badge) / menu`
- 데스크톱 사이드바: 동일 아이콘 + `calendar` 추가

### 메모리 룰 HTML 주석 명시
파일 상단 메타 주석에 4가지 룰 명시:
1. Dashboard 그리드 1fr 의도 — minmax(0,1fr) 금지
2. 월간 도넛 가로 스크롤 — flex-wrap 금지
3. BottomNav: height + paddingBottom 패턴
4. viewport 단위 분기 (Android 100svh / iOS Safari 100dvh / iOS PWA 100vh)

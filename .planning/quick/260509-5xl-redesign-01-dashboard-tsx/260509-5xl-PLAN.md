<design_rules_v011>
**§6.2 Stat Card negative rule (이번 사건의 핵심):**
- 통계 카드 숫자(text-display 28px) 기본 색은 `text-primary` (흰색/검정)
- **위험 임계치(threshold) 일 때만** 숫자를 status 색으로 전환
- 카드 좌측 3px 색바: 해당 status 의 `bar` 변종

DashboardPage 4종 매핑:
| 카드 | 정상치 숫자 색 | 임계치 조건 | 임계치 숫자 색 | 좌측 3px 색바 |
|---|---|---|---|---|
| 점검 미완료 | text-primary | `incomplete > 0` (= 항상 임계치) | --status-danger | --status-danger-bar |
| 미조치 항목 | text-primary | `unresolved > 0` | --status-fire | --status-fire-bar |
| 오늘 일정 | text-primary | (임계치 없음 — 정보 카드) | (없음 — 항상 text-primary) | --border-default (약회색) |
| 승강기 고장 | text-primary | `elevatorFault > 0` | --status-danger | `> 0` 일 때 --status-danger-bar, 그 외 --status-safe-bar |

**§7.1 빠른 도구 일관성:**
- 시안 결정: 빠른 도구 4종 모두 동일 회색 톤 (배경 surface-sunken, 아이콘 text-secondary)
- 기존 페이지의 카드별 컬러 배경 (`rgba(59,130,246,.13)`, `rgba(239,68,68,.13)` 등) 모두 제거
- 이모지(🗺️📈🚨🍱) 사용 금지 — Lucide 아이콘으로 교체:
  - 도면 점검 → `Map`
  - DIV 트렌드 → `BarChart3`
  - 고장 접수 → `Siren` (회색, fire 강조 없음)
  - 직원 서비스 → `Users`

**§6.3 카테고리 카드 (월간 도넛 카드):**
- 카드 좌측 색바로 진척률 표현 (Donut 의 color prop 그대로 — Progress Color Rule 적용된 m.color 가 백엔드에서 옴)
- 0% 카드는 opacity 0.6 (Donut 컴포넌트가 이미 처리)

**§6.4 Backgrounds:**
- 유일한 그라디언트 2종: "오늘 점검 대상" 배너 + 저장 버튼
- 시안의 모바일 배너: `linear-gradient(100deg,rgba(37,99,235,.17),rgba(14,165,233,.08))` → Tailwind arbitrary value 또는 인라인 CSS class 정의
- 데스크톱 배너: `linear-gradient(135deg,rgba(37,99,235,.10),rgba(14,165,233,.05))`

**§6.5 Hover:**
- border-color default → strong + translateY(-1px) 또는 background raised → sunken
- Tailwind 로: `hover:border-border-strong hover:-translate-y-[1px] transition-all`

<conversion_strategy>
**시안 → TSX 변환 매핑:**

1. **모든 `style={{...}}` 제거 → Tailwind 또는 토큰 변수 클래스로**
   - 색: `color: 'var(--t1)'` → `text-text-primary` (또는 `text-[var(--text-primary)]`)
   - 배경: `background: 'var(--bg2)'` → `bg-surface-raised`
   - 테두리: `border: '1px solid var(--bd)'` → `border border-border-default`
   - 패딩/마진: `padding: '8px 13px'` → `px-3 py-2` (또는 토큰 spacing util `p-card-sm` 등)
   - 폰트: `fontSize: 13` → `text-label` 또는 `text-[13px]` (12px 이상만)
   - radius: `borderRadius: 12` → `rounded-md`
   - flex/grid: `display: 'grid', gridTemplateColumns: 'repeat(4,1fr)'` → `grid grid-cols-4`
   - gap: `gap: 7` → `gap-[7px]` 또는 `gap-2` (8px) 로 8pt 그리드 정렬

2. **9/10/11px 폰트 → 12px+ 로 승격 (메모리 룰 절대 준수)**
   - 시안 HTML 도 일부 8/9px 잔존할 수 있으나 TSX 는 무조건 12px 이상
   - RoleLabel(8px) 은 ui-index.tsx 안에 있어 페이지 외부 — 그대로 둠
   - DashboardPage 본문의 fontSize 8/9/10/11 모두 12px(text-caption) 이상으로 승격
   - StatusBadge fontSize:8 (ui-index.tsx 외부 컴포넌트) → 그대로 둠

3. **인라인 hover 핸들러 (onMouseEnter/onMouseLeave 로 style 변경) → Tailwind hover:** **
   - `onMouseEnter={e => { e.currentTarget.style.borderColor = 'var(--bd2)' }}` 패턴 전부 제거
   - `hover:border-border-strong hover:-translate-y-px hover:bg-surface-sunken transition-all duration-150` 로 대체

4. **그라디언트 배너 처리:**
   - Tailwind arbitrary value 사용: `bg-[linear-gradient(100deg,rgba(37,99,235,.17),rgba(14,165,233,.08))]`
   - 또는 `style={{}}` 의 유일한 잔존 영역으로 허용 (단, 색만 — 다른 속성 금지)
   - **결정:** Tailwind arbitrary value 우선 시도. 실용성 위해 그라디언트 단일 속성 인라인 허용 (must_haves truth 의 "인라인 style 0개" 룰의 유일 예외 — 단 그라디언트 라인 1줄만)
   - **수정: 단순화** — 그라디언트도 Tailwind arbitrary value 로 통일. 인라인 style 0개 룰 엄격 준수.

5. **Lucide 아이콘 도입:**
   - 기존 이모지(🗺️📈🚨🍱) 빠른 도구 4종 → Lucide `Map`, `BarChart3`, `Siren`, `Users` 로 교체
   - import: `import { Map, BarChart3, Siren, Users } from 'lucide-react'`
   - lucide-react 0.454.0 이미 dependencies 에 있음 (CLAUDE.md 확인됨)

6. **§6.2 Stat Card negative rule 정확 적용:**
   - 시안의 mobile 통계 카드 4종 색 구조 그대로:
     - 정상치: 숫자 = `text-text-primary`, 색바 = 카드별 status bar
     - 임계치 조건 분기로 숫자 색 전환
     - "오늘 일정" 카드는 숫자가 무조건 text-primary, 색바는 border-default (회색)
   - 데스크톱은 동일 룰 + 검사도래 보조 배지 위치 유지

7. **빠른 도구 4종 일관성:**
   - 모바일 + 데스크톱 모두: 배경=surface-sunken, 아이콘=text-secondary, 라벨=text-primary, 보조설명=text-tertiary
   - 시안의 컬러 배경 (`rgba(...)`) 패턴 전부 제거

8. **유지할 동작 (메모리 룰):**

## What Was Done

### Task 1 — DivUnderPicker + DivTrendSubview (commit e1085fc, ~190줄 영역)

- **DivUnderPicker** (948~1004): 외곽 + selection highlight + 위·아래 그라디언트 마스크 + 스크롤 컨테이너 + 항목 div 마크업/스타일 v0.1.1 매핑. 활성 항목 폰트 13px/700 → `text-label font-bold text-text-primary`, 비활성 11px → 12px `text-caption font-normal text-text-primary` (노안 친화 §1.1).
- **DivTrendSubview** (1005~1136): 외곽 fixed 컨테이너 + 헤더 + ✕ → `<X size={16}>` + 차트 컨테이너 + 폴리라인 label div + 수치 테이블 마크업 v0.1.1. SVG attribute(fontSize 11/9/12 / fontFamily / fill / stroke / polyline / circle / text) 그대로 — 차트 좌표 화이트리스트. 단 circle fill 인라인 `'var(--bg2)'` → `'var(--surface-raised)'` 1건 매핑.

## Spacing Scale

Source: `tailwind.config.js:99-117` spacing override (identical to sketch inline px). **⚠ Override trap — the numeric class does NOT equal 4×N above 6.**

| Token class | Value | Usage |
|-------------|-------|-------|
| `p-1 / gap-1` | 4px | Icon gaps, dot spacing |
| `p-2 / gap-2` | 8px | Compact element spacing, chip gaps |
| `p-3 / gap-3` | 12px | Card inner padding, field gaps |
| `p-4 / gap-4` | 16px | Default element spacing, desktop stack gap |
| `p-5` | 20px | — |
| `p-6` | 24px | Section padding |
| `w-7 / h-7` | **32px** | Header buttons·toggles (⚠ NOT 28px) |
| `w-8 / h-8` | **48px** | Large icon boxes (⚠ NOT 32px) |
| `h-12` | 48px | Header shell container height (unaffected by override) |

**Radius:** `rounded-sm`=8 · `rounded-md`=12 · `rounded-lg`=16 · `rounded-pill`=99.

**Exceptions for this phase:**
- Header toggle switch track = **32×18px** → `w-7` + `h-[18px]` arbitrary (18 is not on the scale).
- Fullscreen/zoom overlays pin to safe-area insets: `top:var(--sat,0px)` / `bottom:calc(54px+var(--sab,0px))` (measured by `index.html` inline script). Never bare `100vh` — shell uses `IS_ANDROID?100svh:100dvh`.
- Zoom scale factors (2.2×–2.5×) are transform values, not spacing.

**Accent (`#3b82f6`) reserved for:** primary save-button gradient (`#1d4ed8→#0ea5e9`, decorative → inline `style`), focused input border (`.inp:focus`), 비화재보-selected toggle (`sel-non` = `border-accent bg-[rgba(59,130,246,.13)] text-[#60a5fa]`), desktop calendar `today` cell, nav active left-border (`--acl`). **Never** apply accent to all interactive elements.

**Destructive:** `#ef4444` (danger-bar) — fire-alarm takeover, 화재보 toggle, ACK-required framing. No delete actions in this phase.

**Data-driven / decorative color rule:** gradients (`alarm-chip`, `btn-save`, `logo-mark`), and any `--fire/--danger/--safe/--c-*` short-alias value → inline `style={{...}}` or `bg-[var(--x)]` (short aliases are CSS-vars only, NOT Tailwind classes). Unknown hex not in tokens → `text-[#hex]` / `bg-[#hex]` arbitrary.

**Negative rule (§6.2):** non-threshold cards (stat cards, tool cards, donut, schedule) MUST NOT borrow status colors. Status color appears ONLY on the semantic surface it belongs to (alarm=live card+chip, safe=LIVE dot+정상, gray=maint).

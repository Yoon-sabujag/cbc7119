S4 v2 — 데스크톱 2열 제출용 탭 (W5)

v3 변경 (사용자 피드백 반영)

  • 사진 인디케이터 앞에 "사진 :" 라벨 추가
  • 사진이 조치 전/후 둘 중 하나라도 없으면 저장 버튼 비활성화 + 인디케이터 자리에 "사진 부족 — 저장 불가" 안내

v2 변경

  • 체크박스 위치: 입력칸 왼쪽 가로축 중앙 정렬 (input-row 안)
  • 10초 디바운스 제거 — 입력 즉시 저장
  • 세번째 줄 2분할: 좌측 = 사진 유무 chip / 우측 = 저장 인디케이터 (저장버튼 우측 모서리 열맞춤)

카드 3줄 구조

  1. info-line: {location} | {description} (읽기 전용)
  2. input-row: [체크박스][textarea (flex:1)][저장 버튼]
  3. meta-row: [사진 유무 chip 2개] · · · [저장 인디케이터]

사진 인디케이터 상태

  • 조치 전 ✓ safe (녹) — photo_keys.length > 0
  • 조치 전 ✗ danger (적) — photo_keys 비어있음
  • 조치 후도 동일 로직 (resolution_photo_keys)
  • 한쪽이라도 ✗ → 저장 버튼 비활성화 (PPT 슬라이드 빈 사진 방지)

저장 인디케이터 4 상태

  • — (미선택) tertiary 회색
  • 저장됨 — safe (녹)
  • 변경됨 — warning (노)
  • 저장중... — accent (파)

저장 흐름 (디바운스 제거)

  • textarea 변경 시 → 즉시 인디케이터 변경됨 → PUT 요청 → 응답 시 저장중 → 완료 시 저장됨
  • 저장 버튼 = 명시적 저장 (디바운스 없이 즉시)
  • 체크박스 토글도 즉시 PUT

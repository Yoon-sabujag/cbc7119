v3 변경 (사용자 피드백 반영)

  • segmented 좌우 토글 → 단일 토글 버튼 (누르면 미완료↔완료 전환)
  • 라벨에 "제출" 붙임: 제출 미완료 / 제출 완료
  • 저장 버튼: 제출 미완료 상태에서는 비활성화. 제출 완료 토글 후에만 활성 (dirty)

버튼 상태 매트릭스

상태 토글 버튼 저장 버튼
초기 미완료 제출 미완료 (warning) 비활성화
완료로 토글 (미저장) 제출 완료 (safe) 저장 * (dirty 노랑)
저장 완료 (lock) 제출 완료 (safe) 🔒 종결
admin 미완료로 복귀 제출 미완료 (warning) 저장 * (dirty)

Lock 해제 (admin 전용)

  • 종결 상태에서 admin 만 토글 활성. assistant 는 disabled
  • admin 이 다시 "미완료" 토글 후 저장 → lock 해제 + 모든 mutation 다시 허용

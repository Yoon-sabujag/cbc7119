v2 변경점

  • ↑↓ 버튼 제거 — 카드 좌측에 드래그 핸들 ⋮⋮ 추가. 더 직관적, 한번에 멀리 이동 가능
  • 체크 자동 순서 — 새로 체크하면 자동으로 마지막 번호 + 구분선 위 맨 아래에 배치. 별도 조작 불필요
  • 드래그 중 표시 — 들고 있는 카드는 흐릿/축소, 드롭 위치는 파란 막대로 표시 (시안에서 #2 카드가 그 상태)

인터랙션

  • 체크 ON → 자동으로 마지막 번호(#N+1) 부여, 위치는 구분선 위 맨 아래
  • 체크 OFF → 구분선 아래로 이동 + 남은 카드 1,2,3 으로 renumber
  • 드래그 → 핸들 잡고 위/아래로. 데스크톱만 (제출용 탭 자체가 데스크톱 전용)
  • 미선택 카드 드래그 → 핸들 흐림(25%), cursor not-allowed (가이드 only)

DB / API

  • legal_findings.submission_order INTEGER DEFAULT 0 추가 (migration 0088)
  • 새 API PUT /api/legal/:id/submission-order body { findingIds: string[] } — 단일 트랜잭션 일괄 renumber
  • 드래그 drop / 체크 토글 모두 같은 API 호출. 클라이언트는 항상 선택된 ID 의 ordered list 만 보냄
  • generate.ts: ORDER BY submission_order ASC, created_at ASC

드래그 구현

  • HTML5 native drag-and-drop (draggable + onDragStart/Over/Drop) — 추가 라이브러리 0
  • 4건 max 정도라 native 로 충분. 시각 효과만 인라인 스타일로

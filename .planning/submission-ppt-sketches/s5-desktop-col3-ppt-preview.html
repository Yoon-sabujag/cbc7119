  • 헤더 문구: PPT 미리보기 · 선택 N건 · 표지 + 슬라이드 M장 → 지적사항 조치 작업사진 N건
  • 저장하기도 10초마다 자동저장 추가
  • 저장 인디케이터 위치: 저장하기 버튼 아래쪽 높이에 맞춰서 버튼의 왼쪽 (같은 가로 라인, 버튼 좌측 옆에 bottom 정렬)
  • PPT 용지: 가로형 A4 (297×210mm) — presentation.xml 의 sldSz cx=10692000 cy=7560000
  • 미리보기 슬라이드 aspect-ratio 도 297/210 으로 (사용자: "미리보기는 상관 없지만" — 일관성 위해 같이 적용)

자동 저장 흐름 (10초 주기)

  • 2열 제출용 탭에서 선택/라벨 변경 시 → 3열 인디케이터 변경됨
  • 10초 idle → 자동으로 PPT 재생성 + R2 업로드 → 저장중 → 저장됨
  • 저장하기 버튼 클릭 = 즉시 저장 (idle 대기 취소)
  • 저장 완료 시 schedule_items.ppt_file_key 갱신 + 1열 카드의 "지적조치사진" 버튼 활성화

인디케이터 4 상태

  • 저장됨 · N초 전 — safe
  • 변경됨 · 자동저장 대기 — warning

  • 저장 실패 · 재시도 — danger (실패 시)

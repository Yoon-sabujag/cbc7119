v3 변경점

  • 미포함 카드 — textarea readonly (점선 border, 회색). 수정 불가
  • 순서 뱃지 — textarea 좌측, 체크박스 자리. 선택 시 #1, #2 …
  • PPT hint 위치 — meta-row 의 사진 chip 우측, 저장상태 사이
  • 사진 chip 정렬 — textarea 좌측 라인과 동일 (들여쓰기 38px)

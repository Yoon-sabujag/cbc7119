S1 — 모바일 카드 (W1 대상)

모바일에서는 작업 X. 다운로드 2개만 제공.

변경점

  • 각 점검 카드 하단에 border-top: 1px dashed 로 구분 후 다운로드 영역 추가
  • 버튼 2개 동일 flex:1 / height:36px / radius:8px / surface-sunken 배경

버튼 상태 매트릭스

  • 결과내역서: round.reportFileKey 있으면 active → window.open('/api/uploads/' + key). 없으면 disabled (라벨 "미업로드")
  • 지적조치사진: round.pptFileKey 있으면 active → 동일 패턴. 없으면 disabled (라벨 "미생성")

제출 상태 배지

  • 제출 미완료 = warning (주황)
  • 제출 완료 = safe (녹색)
  • ※ 카드 좌측 strip 색도 status 따라 분기 (미완료=warning bar / 완료=safe bar) — 기존 finding count 기반 색 룰은 그대로

W1 작업 범위

다운로드 영역(.download-row)만 신규 추가. status 배지/색은 W2+W3 에서 같이.

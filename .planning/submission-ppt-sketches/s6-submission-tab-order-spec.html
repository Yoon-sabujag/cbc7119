새로 추가되는 것 (시각)

  • 순서 뱃지 — 선택된 카드 좌상단에 #1, #2, ... (accent 색)
  • ↑↓ 버튼 — 뱃지 옆. 맨 위 카드 ↑ disabled / 맨 아래 카드 ↓ disabled
  • 우측 hint — "PPT 1페이지 좌측" 처럼 어디로 가는지 즉시 표시
  • 정렬 — 선택 카드를 order ASC 로 상단 → 미선택은 기존 status/createdAt 룰

변경 없는 것

  • 체크박스, 라벨 textarea, 저장 버튼, 사진 chip, 저장 인디케이터 — 위치/디자인 그대로
  • 미선택 카드는 순서 row 가 아예 안 보임 (체크 시 등장)

DB / API

  • legal_findings.submission_order INTEGER DEFAULT 0 추가 (migration 0088)
  • 새 API PUT /api/legal/:id/submission-order body { findingIds: string[] } — 트랜잭션으로 일괄 renumber
  • generate.ts: ORDER BY submission_order ASC, created_at ASC

동작 시나리오

체크 ON아직 0번이면 → 현재 최대값 + 1 자동 부여. 카드는 선택 목록 맨 아래로.
체크 OFF해당 카드 order=0 으로. 남은 카드를 1, 2, 3, ... 로 자동 renumber (빈 번호 없음).
↑ 클릭해당 카드와 바로 위 카드의 order 를 swap. 우측 "PPT N페이지 좌/우" hint 도 즉시 갱신.
↓ 클릭해당 카드와 바로 아래 카드의 order 를 swap.
저장↑↓/체크 변경 즉시 PUT submission-order 호출 → 우측 3열 미리보기 + PPT 생성 모두 새 순서로.
